# Дневник смен водителя

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
По пользовательскому ТЗ: Python, FastAPI, SQLAlchemy, SQLite, Pydantic, Pytest; HTML, CSS и JavaScript.

## Users
Один водитель, который вручную записывает завершённые поездки и сверяет доход за выбранный день.

## Capabilities and Constraints
Выбор дня, шесть показателей сводки, список по времени начала, добавление поездок, серверная валидация и уникальный ID. Комиссия вводится абсолютной суммой в тенге. День определяется датой начала с переданным часовым поясом. Не предусмотрены регистрация, GPS, расстояния, редактирование и удаление.

## Brand Commitments
Русский интерфейс, название из ТЗ, визуальная опора на приложенный скриншот. Пользователь поручил улучшить расположение кнопок.

## Evidence on Hand
ТЗ пользователя; приложенный скриншот; начальные записи в data/trips.json из примера ТЗ.
